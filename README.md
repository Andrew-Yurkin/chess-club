## 🔗 Live Demo

https://andrew-yurkin.github.io/chess-club/

## Стек

- HTML5 (семантическая верстка)
- SCSS используется только как препроцессор → компилируется в CSS
- Vanilla JavaScript (без библиотек и фреймворков)
- Vite — только для сборки и деплоя

❗ В проекте не используются JS-фреймворки и UI-библиотеки.

## Установка и запуск

### 1. Клонировать репозиторий

git clone https://github.com/Andrew-Yurkin/chess-club.git

### 2. Перейти в папку проекта

cd REPO

### 3. Установить зависимости


npm install

### 4. Запустить dev-сервер

npm run dev

Проект откроется по адресу:
http://localhost:5173
